# Hypedrive Brand Assets

Public brand assets for Hypedrive. Served via jsDelivr CDN.

## Logos

| Asset | CDN URL (pinned) |
|-------|---------|
| Full Logo SVG (light backgrounds) | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-full.svg` |
| Full Logo PNG (light backgrounds) | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-full.png` |
| Full Logo SVG (dark backgrounds) | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-full-dark.svg` |
| Full Logo PNG (dark backgrounds) | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-full-dark.png` |
| Icon SVG | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-icon.svg` |
| Icon PNG | `https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-icon.png` |

`logo-full` is near-black ink (`#18181b`) for light backgrounds. `logo-full-dark` is
off-white ink (`#fafafa`) for dark backgrounds. Both share the same rose->red gradient
arrow accent, which reads fine on either background.

## Usage

### In HTML/Email
```html
<img src="https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@e016a5a/logos/logo-full.png" width="150" height="36" alt="Hypedrive" />
```

### Latest (may take up to 12h to update after push)
```
https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@main/logos/logo-full.svg
```

### Pin to specific commit (recommended for emails)
```
https://cdn.jsdelivr.net/gh/ShivamGupta-SM/hypedrive-assets@{commit-sha}/logos/logo-full.svg
```
